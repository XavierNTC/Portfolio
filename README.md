# 🌐 Portfólio Pessoal - Gabriel Xavier Viana

Este é o meu portfólio pessoal desenvolvido com foco em apresentar minhas habilidades como desenvolvedor Front-end. O projeto foi construído utilizando **HTML5**, **CSS3** e **JavaScript puro**, com uma estrutura limpa, responsiva e de fácil navegação.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5**: Estruturação semântica do conteúdo.
- **CSS3**: Estilização moderna com uso de Flexbox e Grid Layout.
- **JavaScript (Vanilla)**: Funcionalidades interativas, como alternância entre temas claro e escuro.

---

## 📄 Funcionalidades

- **Seção Início**: Apresentação pessoal e chamada para ação.
- **Seção Trajetória**: Breve resumo da minha jornada profissional e acadêmica.
- **Seção Portfólio**: Exibição de projetos desenvolvidos, com links para visualização.
- **Modo Escuro/Claro**: Alternância de tema para melhor experiência do usuário.
- **Links para Redes Sociais**: Acesso direto ao meu [GitHub](https://github.com), [LinkedIn](https://www.linkedin.com), [WhatsApp](https://api.whatsapp.com) e [Instagram](https://www.instagram.com).

---
